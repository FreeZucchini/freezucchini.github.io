SPACE SYSTEMS

TVAC Qualification

My contribution towards qualifying a 1U CubeSat.

THE PROJECT

What was it?

To launch a satellite into space it must pass Thermal-Vacuum(TVAC) Qualification so that we know it will handle space conditions. I contributed to the TVAC setup and debugging of APSS-2, the CubeSat we were qualifying.

TECHNICAL CONCEPTS

What was involved?

  • TVAC Interface Setup
  • Payload Sensor Debugging
  • TVAC Setup Troubleshooting
  • Test Script Debugging
  • Control Systems Sensor Calibration

MY CONTRIBUTION

What I did

I was responsible for ensuring all the Avionics on APSS-2 were functioning for the test. I also helped out with debugging the TVAC test script and setup when we encountered issues before and after qualification. On the side I was also the main engineering responsible for calibrating all the sensors on the flight-payload which involved testing a high power control systems payload.

ENGINEERING CHALLENGE

A challenge I faced

The test script was boot-looping which delayed qualification a lot. We investigated and narrowed the issue to a voltage drop across the interface cables that go from the outside to the inside of the TVAC chamber. I fixed it by compensating for the voltage drop and we also installed a new interface cable with half the resistance and double the number of GND paths that go from the power supplies outside the chamber to the payload.

TAKEAWAY

What I learned

This was my first experience debugging a full space systems payload and also my first time seeing a real CubeSat Qualification. I learned a lot about the testing process and what makes a good test plan. I also understood the importance of good documentation.
