SPACE SYSTEMS

Radiation Detector

A space-rated radiation detection payload developed for the APSS-3 CubeSat.

THE PROJECT

What was it?

The radiation detector was designed to measure radiation events using a silicon photomultiplier and analogue signal-processing circuitry. The payload was developed for use on the APSS-3 CubeSat.

TECHNICAL CONCEPTS

What was involved?

  • Analogue signal processing
  • Silicon photomultipliers
  • Op-amp circuits
  • PCB design
  • DC-DC Boosters
  • Embedded systems

MY CONTRIBUTION

What I did

I worked on the analogue signal-processing circuitry, and PCB design. I also soldered, and tested the PCB successfully. Soldering was done using a hot-plate and heat gun and testing was done using a power supply, multimeter and oscilloscope.

ENGINEERING CHALLENGE

A challenge I faced

During testing, I had issues getting the opamp to output the correct amplified voltage. I went component by component and traced out the issue to a short between two pins of the opamp. Another issue I encountered is the I2C transmission for the temperature sensor timing-out. I fixed this by testing the TI I2C libraries on a test sensor and porting that code to this PCB.

TAKEAWAY

What I learned

This project strengthened my understanding of analogue signal conditioning as the board features an amplifier and peak detector. I also learned how to route a DC-DC boost converter and how to debug communication protocols like I2C and SPI.
