FEATURED PROJECT

Radiation Detector

A space-rated radiation detector designed for the APSS-3 CubeSat using an SiPM and analogue signal processing circuitry.

THE PROJECT

Overview

The radiation detector measures radiation events using a silicon photomultiplier. The detector output is passed through an analogue signal-processing stage before being digitised.

TECHNICAL CONCEPTS

What I used

Analogue Electronics SiPM Op-Amps Signal Processing PCB Design Embedded C

MY CONTRIBUTION

What I did

I worked on the analogue signal-processing circuitry, component selection and PCB design. I also contributed to hardware testing and debugging to verify that the detector behaved as expected.

ENGINEERING CHALLENGE

A challenge I faced

During testing, the detector output contained unexpected noise. I investigated the signal path and hardware configuration to identify possible sources before modifying and retesting the circuit.

WHAT I LEARNED

Key takeaway

This project strengthened my understanding of analogue signal conditioning and low-level measurements. It also taught me to approach hardware debugging systematically using measured behaviour.
