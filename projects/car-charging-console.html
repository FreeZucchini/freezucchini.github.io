Car Charging Console

A cloud-connected application for controlling and scheduling an electric vehicle charging system.

THE PROJECT

What was it?

I built a web application for managing an electric vehicle charging system. The application allows a user to start and stop charging, view the vehicle state and configure a charging schedule.

The project uses a Svelte frontend, a C# backend hosted in Azure Functions and Azure IoT Hub to communicate with a simulated vehicle. This gave me experience building a complete system across the frontend, backend, cloud and device layers.

TECHNICAL CONCEPTS

What was involved?

  • Svelte Frontend
  • C# Backend
  • REST APIs
  • Azure Functions
  • Azure IoT Hub
  • Device Communication

MY CONTRIBUTION

What I did

I developed both the frontend and backend of the application. The frontend was built using Svelte, while the backend was implemented in C# using Azure Functions.

I created REST API endpoints for starting and stopping charging and for configuring charging schedules. These commands were then sent through Azure IoT Hub to a simulated vehicle device.

The simulated car is a simple C# console program that mimics a real life electric car.

I also implemented persistent client-side state so that charging status, battery percentage and charging schedules could be retained by the application.

ENGINEERING CHALLENGE

A challenge I faced

I encountered a really annoying bug where each time I set or cancelled the charging schedule the schedule would set but the response would return as a 502 error. I recognised that the 502 error was coming from the second POST request sent and I setup debug prints into the console to find out why. I isolated the bug to one line where the response to the set and cancel schedule commands was "OK" converted into bytes when GetBytes only accepts JSON and not a string.

This required me debugging across multiple layers which improved my attention to detail, and taught me how errors can propogate through an application.

TAKEAWAY

What I learned

This project gave me practical experience building a complete cloud-connected system as it was my first time using Azure. I developed a greater appreciation for how IoT systems work and this has given me more motivation to do more IoT projects.

I also developed a better understanding of REST APIs and its architecture, cloud services and HTTP status codes.
